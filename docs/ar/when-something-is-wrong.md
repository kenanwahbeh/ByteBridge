# عندما تحدث مشكلة

ابدأ دائماً بـ **سطر الحالة** أعلى النافذة. فهو يجيب على السؤالين
المهمّين: هل الخدمة التي في الخلفية تعمل؟ وهل ByteBridge يجيب فعلاً؟

## معنى سطر الحالة

| المكتوب | المعنى | ماذا تفعل |
| --- | --- | --- |
| **● يعمل** (أخضر) · *الخدمة: تعمل* | كل شيء سليم. | لا شيء. |
| **● متوقف** (رمادي) | أحدهم أوقف البوابة من *سيرفر ويب*. | افتح **سيرفر ويب** واضغط **تشغيل**. |
| **● قيد التشغيل، أو تعذر الاتصال** (برتقالي) | الخدمة تعمل لكنها لا تستطيع الإجابة بعد. | انتظر بضع ثوانٍ. إن بقي برتقالياً فهناك برنامج آخر يستخدم نفس المنفذ — اسأل المطوّر، أو غيّر **المنفذ** في *سيرفر ويب* وأخبره بالرقم الجديد. |
| **● غير يعمل** (أحمر) · *الخدمة: متوقفة* | الخدمة التي في الخلفية متوقفة. | اضغط **بدء الخدمة** في سطر الحالة. |
| *الخدمة: غير مثبتة* | الخدمة غير موجودة. | ثبّت ByteBridge من جديد. قواعد بياناتك ومفتاحك يبقون محفوظين. |

## بطاقة قاعدة بيانات تُظهر "غير متصل" بالأحمر

قاعدة البيانات مفعّلة، لكن ByteBridge لا يستطيع الوصول إليها. غالباً
لأحد هذه الأسباب:

- الجهاز الذي يحمل قاعدة البيانات مطفأ، أو برنامج سيرفر قاعدة البيانات
  عليه متوقف. شغّله من جديد، وستعود البطاقة خضراء وحدها خلال دقيقة
  تقريباً.
- تغيّرت كلمة سرها أو مسارها، أو حُفظت دون اختبار ناجح. استخدم **تعديل** على البطاقة، ثم
  **اختبار الاتصال**.

## "فشل الاتصال" عند إضافة قاعدة بيانات أو تفعيلها

الرسالة التي تحتها هي شرح قاعدة البيانات نفسها (وهي بالإنكليزية). أشهرها:

- *unable to complete network request* — **السيرفر** أو **المنفذ**
  خطأ، أو برنامج سيرفر قاعدة البيانات لا يعمل.
- *Your user name and password are not defined* — اسم المستخدم أو
  كلمة السر خطأ.
- *I/O error … open* أو *file … not found* — مسار **قاعدة البيانات**
  خطأ، أو يشير إلى ملف على جهاز آخر.

## المطوّر يخبرك برقم خطأ

المطوّرون يرون أرقاماً قصيرة. معناها بالنسبة لك:

| الرقم | بكلمات بسيطة | يُحَلّ عادةً بـ |
| --- | --- | --- |
| **502** أو **1033** من Cloudflare | النفق وصل إلى الجهاز لكن لم يُجِب أحد. | التأكد أن سطر الحالة أخضر، وأن الجهاز شغّال وليس في وضع السكون. |
| **401** | كلمة السر (مفتاح API) خطأ أو غير موجودة. | إرسال المفتاح الحالي له مرة أخرى — ربما ضغط أحدهم **مفتاح جديد**. |
| **429** | أرسل مفاتيح خاطئة كثيرة، فحُظر لفترة. | الانتظار دقيقة، ثم استخدام المفتاح الصحيح. |
| **409** | قاعدة البيانات تلك **غير متصل**. | ضغط **متصل** على بطاقتها. |
| **404** مع اسم قاعدة بيانات | لا توجد قاعدة بيانات بهذا الاسم. | إخباره بـ **اسم الاتصال** الذي استخدمته بالضبط. |

## قبل أن تطلب المساعدة

جهّز هذه الأمور، فهي تجيب على معظم الأسئلة مباشرة:

1. رقم الإصدار، من **تعليمات ← حول ByteBridge**.
2. ما يقوله سطر الحالة بالضبط، أو صورة شاشة للنافذة.
3. السجل: **تعليمات ← حول ByteBridge ← فتح مجلد السجلات** يفتح مجلداً
   فيه ملف لكل يوم. أرسل ملف اليوم الذي حدثت فيه المشكلة.

يسجّل السجل كل طلب ونص الاستعلام الذي نفّذه. هذا النص فيه أسماء جداولك
وأعمدتك، وإن كتب المطوّر قيمة داخل الاستعلام نفسه — اسم زبون أو بريده
مثلاً — فهذه القيمة موجودة في السجل أيضاً. افتح الملف وانظر فيه قبل
إرساله، ولا ترسله إلا لمن تثق به.

**لا ترسل أبداً مفتاح API أو كلمة سر قاعدة البيانات** لأي أحد يعرض
المساعدة، إلا إن كان هو الشخص المفترض أن يملكها. لا أحد يعمل على
ByteBridge سيطلبها منك أبداً.

## كلمات قد تسمعها

| الكلمة | معناها |
| --- | --- |
| **قاعدة البيانات** (Database) | المكان الذي يحفظ فيه برنامج عملك معلوماته. يعمل ByteBridge مع قواعد بيانات *Firebird*. |
| **API** | طريقة يطلب بها برنامجٌ معلوماتٍ من برنامج آخر. ByteBridge يعطي قاعدة بياناتك واحدة. |
| **مفتاح API** | كلمة السر التي يجب أن يحملها كل طلب. |
| **البوابة** (Gateway) | اسم آخر للجزء من ByteBridge الذي يجيب على الطلبات. |
| **الخدمة** (Service) | برنامج يشغّله Windows في الخلفية، سواء سجّل أحد الدخول أم لا. |
| **النفق** / **cloudflared** | الاتصال الخاص من Cloudflare إلى جهازك، والبرنامج الذي يشغّله. |
| **المنفذ** (Port) | "باب" مرقّم في الجهاز. ByteBridge لا يستمع إلا على باب داخل الجهاز نفسه (`127.0.0.1`)، وليس على شبكتك أبداً. |
| **متصل / غير متصل** | هل سيجيب ByteBridge على الطلبات الخاصة بقاعدة بيانات معيّنة. |
| **صينية النظام** (Tray) | صف الأيقونات الصغيرة بجانب الساعة. |
